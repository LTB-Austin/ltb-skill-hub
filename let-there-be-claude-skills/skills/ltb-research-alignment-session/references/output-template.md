# Output template

Fill this into `[brand]-research-alignment-session.md`. Keep screen numbers and labels; renumber only if an optional module is inserted. Boilerplate screens are listed by label with `boilerplate` and not rewritten.

Gap markers, used verbatim:
- `NEEDED FROM YOU: [what]` — an input we are waiting on. Shown on the slide.
- `TO BE DEFINED WITH [CLIENT]` — a decision only the client can make. Shown on the slide.
- `A QUESTION FOR TODAY: [question]` — a decision to take in the room.
