# Output template

Copy the skeleton below into `[brand]-sales-preview.md` and fill every `[bracket]`. Keep the screen numbers, labels and field names exactly as they are. Part 1 is what goes into the deck. Part 2 stays with the presenter.

Markup (only where shown):
- `[BLUR]` blurs the span that follows, up to the next separator.
- `[Strongly liked]` `[Liked]` `[Disliked]` set the highlight color on screen 07.
- `(Core)` `(Push)` `(Stretch)` set the tier marker on a claim.

Don't use bold, italics, headers or bullets inside a field. A field value is the exact text that goes on the slide.
