# Output template

Copy this skeleton into `[brand]-rsq-claims-lab.md` and fill every `[bracket]`. Keep the screen numbers, labels and slot names exactly as they are: they match the Claude Design template field for field, so the brief can be pasted in top to bottom.

Boilerplate screens (01, 02, 03, 05, 15) are listed by label only. Their copy lives in `deck-structure.md` and does not change. Do not rewrite it into the brief.

Mark emphasis the way the template needs it:
- `(emphasized)` on the one card per screen that gets the gradient tint.
- `==mint==` around the supporting phrase in a key finding.
- `++purple++` around the context phrase in a key finding.
- `*word*` for the emphasized product word in the screen 06 subhead.
- `[BLUR]` before anything the template blurs.
